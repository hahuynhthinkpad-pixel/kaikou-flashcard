# 🎴 KAIKOU Flashcard Studio — 華語開口

Ứng dụng web mã nguồn mở hỗ trợ tạo, quản lý và luyện tập thẻ Flashcard học từ vựng đa ngôn ngữ, đặc biệt tối ưu cho tiếng Trung (Phồn thể / Giản thể).

## 🌟 Đặc điểm nổi bật
- **Đổi tên thương hiệu**: KAIKOU Flashcard Studio — 華語開口.
- **Chế độ thẻ linh hoạt**:
  - Chế độ 2 mặt: `Từ vựng` → `Nghĩa`
  - Chế độ 3 mặt: `Từ vựng` → `Phiên âm / Pinyin` → `Nghĩa`
- **Khóa mặt thẻ khi chuyển bài**: Luôn tự động đưa về Mặt 1 (Từ vựng) khi bấm Trước/Sau/Xáo trộn.
- **Nhập từ nhiều định dạng**: Dán văn bản tự do (`|`, `,`, `Tab`, `-`), tải file Excel (`.xlsx`), Word (`.docx`), PDF, PowerPoint (`.pptx`), CSV, TXT, JSON.
- **Xuất file phong phú**: Xuất ra Slide PowerPoint (`.pptx`), PDF Printable, File HTML độc lập chạy Offline, JSON, CSV.
- **Tích hợp giọng đọc TTS**: Đọc chuẩn tiếng Trung (Đài Loan / Phổ Thông), Nhật, Hàn, Anh, Việt,...

## 🚀 Hướng dẫn chạy dự án
Mở file `index.html` trên bất kỳ trình duyệt web nào hoặc đẩy lên **GitHub Pages**, **Netlify**, **Firebase Hosting** để truy cập trực tuyến.
